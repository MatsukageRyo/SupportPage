プライバシーについて

練習は、このiPhoneの中で。お子さまの名前や連絡先を入力する必要はありません。

対象：こまの教室 1.0 ／ 適用日：2026年11月1日

学習データを外部に送信しません

対局処理と教材の表示は端末内で行います。学習のためのサーバー通信、アカウント登録、広告、アクセス解析、追跡はありません。アプリ内の学習履歴や局面を、運営者・開発者・第三者に送信しません。

アプリは、お子さまの氏名、連絡先、位置情報、写真、音声を収集しません。

アプリ内課金や、ほかの利用者との通信もありません。

端末内に保存するもの

練習を続きから再開し、できたことを表示するために、学習の進み具合、ヒントを使って達成したかどうか、中断した練習の局面や進行状況をアプリの保存領域に記録します。

アプリ独自のクラウド同期はありません。iOSのバックアップに含まれるかどうかは、端末やAppleのサービスの設定に従います。アプリを削除すると、その端末上のアプリの保存内容は削除されます。「Appを取り除く」は書類とデータを保持するため、削除とは異なります。バックアップから復元すると保存内容が戻る場合があります。

読み上げについて

説明カードの読み上げボタンを押したときだけ、端末の日本語音声機能で教材の説明を読み上げます。自動では再生しません。マイクを使った録音や音声入力は行いません。

説明はすべて文字でも読めます。「おうちの 方へ・音とヘルプ」で読み上げボタンを非表示にできます。

保護者向けの外部ページ・お問い合わせ

アプリの「おうちの 方へ・音とヘルプ」に、公開プライバシーポリシー、サポートサイト、メールの連絡先を表示します。外部リンクを選ぶと、保護者の方に計算の答えを入力していただき、正しい答えを入力して「確認して開く」を押した場合だけブラウザやメールアプリを開きます。

外部サイトへのアクセスやメールの送信には通信が発生します。利用するサイト・メールサービスでの情報の取り扱いは、それぞれの提供者のポリシーに従います。

メールでお問い合わせいただいた場合、運営者は送信元のメールアドレスと、お問い合わせに記載された内容を受け取ります。これらは、お問い合わせへの回答と問題の調査に使用します。アプリ内の学習データがメールに自動添付されることはありません。お子さまのお名前、学校名、写真などを送る必要はありません。

このWebページについて

このWebページはGitHub Pagesで公開しています。運営者は、このページにアクセス解析、Cookieを設定する処理、外部フォント、問い合わせフォームを組み込んでいません。

GitHub Pagesでは、GitHubへのログインの有無にかかわらず、安全対策のために閲覧者のIPアドレスが記録・保存されます。GitHubによる情報の取り扱いについては、GitHub Pagesのデータ収集に関する説明とGitHubのプライバシーステートメントをご確認ください。
